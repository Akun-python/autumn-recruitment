# 📐 23-统计学：从入门到精通

> 统计学岗位 = **把不确定性问题翻译成可量化的推断**：描述数据 → 建立分布模型 → 估计参数 →
> 检验假设 → 回归关联 → 贝叶斯更新 → 综合建模。本模块从「描述统计」起步，
> 一路走到「统计学习与建模实战」，共 12 篇 notebook，全部手写实现 + 数值对照，
> 覆盖秋招统计学岗 / 数据科学岗 / 算法岗的统计考点。
>
> 与 00-数学基础（概率论与统计）、17-数据科学（统计推断/AB 实验/因果推断）、
> 18-数据分析（业务指标/分析方法）互补：本模块把**统计学本身**按由浅入深的完整体系讲透。

> 🖼️ 配图与深化：教学 notebook 全部基于 numpy/pandas/scipy/matplotlib/statsmodels/sklearn，自包含可执行，
> 含断言与数值对照（手写 vs 库实现）；绘图统一中文字体并显式 `plt.show()`。

> 📖 **论文配图（`figures/`，全部开放获取、每幅注明出处）**：12 篇每篇至少 1 张真实期刊论文插图，

## 面试高频题型（详见 [高频面试题.md](高频面试题.md)）

- **描述统计类**：均值/中位数/众数对比、方差 vs 标准差、IQR 离群值、偏度/峰度含义
- **概率分布类**：二项 vs 泊松、正态分布 3σ、t 分布 vs 正态、卡方/F 分布用途
- **推断类**：CLT、标准误 vs 标准差、MLE、无偏性、置信区间理解、p 值经典误解
- **检验类**：z vs t 选择、两类错误、功效与样本量、卡方适用条件
- **回归类**：皮尔逊 vs 斯皮尔曼、OLS 假设、R²、多重共线性、回归≠因果
- **贝叶斯类**：先验/后验、共轭、贝叶斯 vs 频率派
- **进阶类**：ANOVA 前提、多重比较修正、偏差方差、交叉验证
