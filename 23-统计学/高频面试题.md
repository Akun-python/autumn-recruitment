## 一、描述统计（10 题）

1. **均值与中位数的区别？** 均值对离群值敏感、利用全部数据；中位数只依赖位置、稳健。
2. **为什么用标准差而不用方差？** 标准差与原始数据量纲一致，便于解释。
3. **IQR 离群值判据？** Q1−1.5·IQR 与 Q3+1.5·IQR 之外为离群点。
4. **偏度正负的含义？** 右偏（正偏）：长尾在右，均值被拉向右侧；左偏相反。
5. **峰度衡量什么？** 尾部厚度/极端值倾向；正态分布 excess kurtosis = 0。
6. **z-score 与 min-max 归一化的区别？** z=(x−μ)/σ 无量纲、对离群值敏感度低；min-max 映射到 [0,1]、对离群值敏感。
7. **箱线图包含哪五个数？** min、Q1、median、Q3、max（+1.5×IQR 离群判据）。
8. **为什么要"先画图再看数"？** 统计量可能掩盖多峰、离群、缺失等结构。
9. **标准差与标准误的区别？** SD 描述单个观测波动；SE=SD/√n 描述样本均值的估计精度，随 n 增大而减小。
10. **众数适用场景？** 类别数据、离散分布的中心位置。

## 二、概率分布（10 题）

11. **伯努利与二项的关系？** 伯努利是一次试验；二项是 n 次独立伯努利的成功次数。
12. **二项何时可近似为泊松？** n 大、p 小，且 np=λ 固定。
13. **泊松分布应用场景？** 单位时间/空间内事件计数：呼叫、点击、缺陷数。
14. **指数分布的无记忆性？** P(T>t+s | T>t)=P(T>s)，已等待时间不影响剩余期望。
15. **正态分布 68-95-99.7 法则？** ±1σ≈68%、±2σ≈95%、±3σ≈99.7%。
16. **t 分布特点？** 小样本尾部更厚（更保守），自由度 ν→∞ 趋于正态。
17. **卡方分布用途？** 方差检验、拟合优度、列联表独立性。
18. **F 分布用途？** 方差比、ANOVA。
19. **标准正态平方和服从什么？** 卡方分布 χ²(ν)。
20. **均匀分布 PDF？** f(x)=1/(b−a)。

## 三、推断统计（15 题）

21. **中心极限定理（CLT）？** 独立同分布、n 充分大时样本均值近似正态，均值 μ、标准误 σ/√n，与总体分布无关。
22. **大数定律与 CLT 的区别？** 大数定律：均值收敛于期望；CLT：均值的分布收敛于正态。
23. **什么是无偏估计？** E(θ̂)=θ；样本方差除 n−1 才是无偏（损失一个自由度）。
24. **MLE 的核心思想？** 选择使观测数据似然函数最大的参数。
25. **正态分布的 MLE？** μ̂=样本均值，σ̂²=Σ(x−μ̂)²/n（注意 n 分母）。
26. **MLE 的三大性质？** 一致性、渐近正态性、渐近有效性。
27. **95% 置信区间怎么理解？** 频率解释：重复抽样，约 95% 的区间覆盖真值；不是"参数落在区间内概率 95%"。
28. **p 值的定义？** H₀ 为真时，观测到当前或更极端数据的概率。
29. **p 值三大误区？** ①不是 H₁ 为真的概率 ②不是效应由偶然产生的概率 ③不代表效应大小。
30. **两类错误？** α：H₀ 真却拒绝（假阳性）；β：H₀ 假却不拒绝（假阴性）。
31. **统计功效？** power=1−β，正确拒绝 H₀ 的概率。
32. **样本量与功效的关系？** 效应越小、σ 越大 → n 越大；α 越小、要求功效越高 → n 越大。
33. **z 检验与 t 检验怎么选？** σ 已知（或 n 很大）用 z；σ 未知小样本用 t。
34. **Welch t 检验？** 不假定等方差的 t 检验，现代统计默认使用。
35. **假设检验五步？** 设假设 → 定 α → 算检验统计量 → 算 p 值 → 下结论。

## 四、进阶检验（10 题）

36. **卡方拟合优度检验？** 观测频数是否符合理论分布；χ²=Σ(O−E)²/E。
37. **卡方独立性检验？** 列联表中两变量是否独立；期望频数=行合计×列合计/总数。
38. **卡方检验适用条件？** 期望频数一般 ≥5；观测独立。
39. **什么时候用非参数检验？** 严重偏斜、有序数据、离群值多、小样本。
40. **Wilcoxon 符号秩与 Mann-Whitney U 区别？** 前者用于配对/单样本中位数，后者用于两独立样本。
41. **Kruskal-Wallis 检验？** 多组比较的非参数版 ANOVA。
42. **多重比较问题？** m 次独立检验累积假阳性概率 = 1−(1−α)^m，m 大时非常可观。
43. **Bonferroni 校正？** α_adj=α/m，最保守。
44. **BH-FDR 校正？** 控制错误发现率（被拒绝中假阳比例），比 Bonferroni 功效高。
45. **FWER 与 FDR 区别？** FWER 控制"至少一个假阳性"的概率；FDR 控制假阳性占比，大规模检验（基因/特征选择）更常用。

## 五、相关与回归（15 题）

46. **皮尔逊与斯皮尔曼区别？** 皮尔逊测线性相关；斯皮尔曼基于秩、测单调关系、抗离群值。
47. **相关系数范围？** [−1,1]；为 0 只表示无线性关系。
48. **OLS 闭式解？** β̂=(XᵀX)⁻¹Xᵀy（含截距列）。
49. **一元回归 β̂₁ 的两种等价形式？** Σ(x−x̄)(y−ȳ)/Σ(x−x̄)² 与 r·s_y/s_x。
50. **R² 含义？** 模型解释的方差比例 = 1−SSR/SST。
51. **调整 R² 为什么要用？** 惩罚特征数量，防止"特征越多 R² 越高"的假象。
52. **残差诊断看什么？** 残差 vs 拟合值无模式（非线性遗漏）、残差近似正态、无自相关。
53. **多重共线性危害？** 系数估计不稳定、标准误膨胀；VIF>10 视为严重。
54. **VIF 公式？** VIF=1/(1−R²)，R² 是该特征对其余特征回归的 R²。
55. **为什么相关≠因果？** 可能存在混杂变量 Z 同时影响 X 和 Y；需要随机化或因果推断。
56. **辛普森悖论？** 合并数据相关性方向可能被群体结构反转，要先分组看。
57. **贝叶斯公式？** P(θ|x) ∝ P(x|θ)P(θ)。
58. **共轭先验？** 先验与后验同族，闭式更新；典型：Beta-二项、Gamma-泊松。
59. **贝叶斯与频率派本质区别？** 参数是随机变量（信念分布）vs 固定未知常数；后验更新 vs 长期频率。
60. **可信区间 vs 置信区间？** 贝叶斯直接给参数的概率分布，可信区间有概率解释；频率 CI 是覆盖频率概念。

## 六、贝叶斯（5 题）

61. **贝叶斯因子是什么？** 两个假设边际似然之比 BF₁₀=P(x|H₁)/P(x|H₀)；BF>3 有证据支持 H₁。
62. **朴素贝叶斯假设？** 特征在给定类别下条件独立；文本分类经典算法。
63. **先验怎么选？** 有领域知识用信息先验；否则用无信息先验（均匀/ Jeffreys）。
64. **后验均值与先验、数据的关系？** 后验均值是"先验信息 + 数据"的加权平均，样本量越大数据权重越大。
65. **贝叶斯更新的流程？** 先验 × 似然 → 归一化 → 后验；新数据到来时后验成为新先验。

## 七、统计学习（10 题）

66. **过拟合的本质？** 模型拟合了噪声，训练好测试差；高方差、低偏差。
67. **欠拟合的本质？** 模型太简单，捕捉不到结构；高偏差、低方差。
68. **偏差-方差分解？** 泛化误差 = 偏差² + 方差 + 不可约噪声。
69. **怎么降低方差？** 更多数据、正则化、集成（bagging/随机森林）。
70. **怎么降低偏差？** 更复杂模型、更多特征、更强表达。
71. **K 折交叉验证思想？** 分成 K 份轮流 1 份验证、其余训练，平均；比单次留出稳。
72. **留一法（LOO）？** K=n 的极端，无偏但方差高、计算贵。
73. **L1 为什么稀疏？** L1 约束面是菱形，最优点常在坐标轴上（系数为 0）。
74. **L2 为什么不平滑为 0？** L2 约束面是圆形，最优解在轴上概率为 0，系数平滑收缩。
75. **Precision/Recall/F1？** P=TP/(TP+FP)；R=TP/(TP+FN)；F1=2PR/(P+R)。
76. **AUC 含义？** ROC 曲线下面积；阈值无关、随机 0.5、完美 1.0；适合不平衡数据。
77. **垃圾邮件重 P 还是 R？** 误杀代价高 → 重精确率；癌症筛查漏诊代价高 → 重召回率。
78. **交叉验证与时间序列？** 时序数据不能随机切分，要用前向链式/滚动窗口。

## 八、面试场景题（10 题）

79. **"平均工资 2 万"为什么员工感觉 8 千？** 少数高薪拉高均值，应报告中位数与分布。
80. **怎么验证新推荐算法有效？** 设计 A/B 实验：指标→样本量→分流→AA/SRM→显著性→上线决策。
81. **两组转化率差异怎么检验？** 两比例 z 检验（等价卡方独立性）。
82. **多组均值比较为什么用 ANOVA？** 两两 t 检验累积假阳性，ANOVA 一次检验整体差异。
83. **p 值不显著能说"无差异"吗？** 不能，只能说"证据不足"，还可能功效不够。
84. **离群值怎么处理？** 先判断来源（真实值/错误值），1.5×IQR 或 z 检测，再决定剔除/变换/稳健方法。
85. **特征高度相关会怎样？** 共线性：系数不稳、标准误膨胀；可用 VIF 检测、PCA/正则化处理。
86. **小样本怎么办？** 用非参数检验、贝叶斯（先验信息）、bootstrap；注意功效不足。
87. **怎么证明 X 导致 Y？** 随机化实验最可靠；观察数据用因果推断（DID/PSM/RDD/IV）。
88. **数据不平衡怎么评估？** 用 AUC/PR 而非准确率；可重采样/加权/阈值调整。
