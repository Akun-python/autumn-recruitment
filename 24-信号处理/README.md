# 🎛️ 24-信号处理：从信号到特征

> 信号处理岗位 = **把波形翻译成可分析的数学对象**：采样 → 变换（DFT/FFT/z）→ 滤波（FIR/IIR）→
> 时频分析（STFT/语谱图）→ 特征提取（MFCC）→ 自适应滤波（LMS）。本模块从「信号与系统基础」起步，
> 一路走到「面试八股」，共 11 篇 notebook，全部手写实现 + 数值对照，
> 覆盖秋招信号处理岗 / 语音算法岗 / 音频算法岗的核心考点。

> 与 02-机器学习、03-深度学习（语音/音频方向应用）互补：本模块把**信号处理本身**按
> 由浅入深的完整体系讲透。
