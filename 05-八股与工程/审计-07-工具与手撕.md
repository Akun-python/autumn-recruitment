# 审计报告：07-工程工具 / 08-高频手撕代码 小白友好度评估

> 审计对象：`05-八股与工程/07-工程工具.ipynb`（60 cells，6 章 + 附录 B1–B9）、`05-八股与工程/08-高频手撕代码.ipynb`（77 cells，11 章）、同名 `.md` 速查版。
> 审计方法：逐 cell 通读全部 markdown 与代码（含输出），按「每章概念 → 定义-类比-示例 完整度 → 代码前是否有『这段代码在做什么、为什么这么写』的解释 → 排序/算法题是否有复杂度分析与逐步过程」评估。

## 三、TOP 10 最需补充"小白解释"的概念或代码段

1. **08-第10章 堆排序 `sift_down`/大顶堆** — 最晦涩句：`for i in range(n // 2 - 1, -1, -1):  # 自底向上建堆`。全程未定义"堆是什么、为什么父≥子、为什么最后一个非叶是 n//2-1、为什么建堆要自底向上"，小白只能抄不能懂。
2. **08-第10章 快排 Hoare 分区** — 最晦涩句：`while i <= j: while nums[i] < pivot: i += 1 ...`。指针相向移动、pivot 取值中点、交换后 i/j 各进一位的循环不变量，无任何标注与样例走查。
3. **08-第7章 KMP `build_next`** — 最晦涩句：`while j > 0 and p[i] != p[j]: j = nxt[j - 1]`。"为什么失配要回退到 next[j-1]"只有一句"失配回退"，next 数组构建是公认第一难点，缺逐步演算（如对 "ababaca" 逐 i 推演）。
4. **08-第5章 顶层 `await`** — 最晦涩句：cell 28/30 的 `await main()` 与附录"所有代码均可用 `python 文件名.py` 直接运行"自相矛盾（顶层 await 在 .py 中是语法错误，仅 IPython/Jupyter 可用）。小白照抄到文件必扑街。
5. **07-第3章 fixture 本质与拓扑排序** — 最晦涩句："pytest 自动拓扑排序执行"。fixture 用"依赖注入"定义、依赖序用"拓扑排序"解释，两个术语都没定义；小白无法理解"为什么 pytest 知道先建哪个 fixture"。
6. **07-第4章 单例 `__new__`** — 最晦涩句：`cls._instance = super().__new__(cls)`。不解释"创建对象的是 __new__ 而非 __init__、为什么这里必须 super().__new__"，三个写法只有代码没有原理。
7. **07-第4章 观察者=回调注册表 / 装饰器模式=组合替代继承** — 最晦涩句："观察者模式的本质就是**回调注册表**"。回调、注册表、组合、继承四个基础词全未定义，用陌生术语定义陌生术语。
8. **08-第6章 LFU 频率桶淘汰** — 最晦涩句：`victim = next(iter(self.freq_map[self.min_freq]))  # 最小频率桶的队首`。频率桶、min_freq 提升/下降逻辑零走查，只有 3 行调用例子，小白无法复述淘汰过程。
9. **08-第3章/第9章 "幂等"** — 最晦涩句：`# 注意：__init__ 每次都会执行，赋值要幂等`（出现 2 次）。一个半抽象术语拦在读 `__init__` 幂等标记、retry 不重试 4xx 两处。
10. **07-第5章 cProfile 输出解读** — 最晦涩句：输出的 `ncalls  tottime  percall  cumtime` 四列零注释。工具讲得全，但小白看到真实 profile 输出依然不知道读哪列。

备选入围：08-第1章"闭包/一等公民"（装饰器定义用未定义术语）、08-第8章+07-第4章"开闭原则"（全文出现 ≥6 次从未定义）、07-第6章"cgroup + namespace 隔离"、07-第1章"HEAD/暂存区/工作区"。
