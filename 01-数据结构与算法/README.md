# 🧮 01-数据结构与算法

> 主语言 **Python**。本模块的目标：建立**模板 + 高频题 + 复杂度意识**三件套。

## 刷题顺序（建议按此推进）

1. **数组 / 哈希**：入门热身，建立刷题手感
2. **双指针 / 滑动窗口**：高频，套路固定
3. **链表**：指针操作为主，注意边界（空、单节点）
4. **栈 / 队列 / 单调栈**：括号类、滑动窗口最大值等
5. **二分查找**：模板 + 边界条件（闭区间/开区间）统一写法
6. **二叉树**：遍历三件套（递归/迭代/Morris），层序是高频
7. **回溯**：模板化（选择/撤销），全排列、组合、子集三件套
8. **贪心**：证明不重要，先积累典型题
9. **动态规划**：重头戏，按状态定义 → 转移 → 初始化 → 遍历顺序四步走
10. **图**：BFS/DFS、拓扑排序、并查集、最短路径
11. **堆**：Top-K 系列（第 K 大、前 K 高频、数据流中位数）
12. **位运算**：常见 trick 积累

## 学习方法

- **10 分钟原则**：一道题思考 10 分钟无思路 → 直接看题解，看懂后**独立重写**
- **模板先行**：每类先总结一份可复用的模板代码，再刷题套模板
- **一题三问**：思路（复杂度）→ 边界（空/溢出/重复）→ 变体（这题还能怎么考）
- **三刷制**：一刷理解、二刷限时、三刷盲写（面试前只刷高频 + 错题）
