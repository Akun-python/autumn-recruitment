# 📡 其他模块前沿技术补充 · 2026-11

> 本页把 2026-11-16～20 arXiv 最新批次映射到仓库模块。它是面试/选题导航，不替代论文复现；数字只在已打开的 arXiv 摘要中使用。

## 04-LLM大模型：推理设置、长程推理与 Mamba-MoE

- [Inference for Reasoning Models](https://arxiv.org/abs/2611.10845)：最大生成长度、答案抽取、量化、batch、attention backend、cache 都会改变结果；**评测配置本身是实验变量**。
- [Info-GRPO](https://arxiv.org/abs/2610.34949)：长思维链 GRPO 的探索-收敛张力，用 latent seed / 轨迹互信息改善多样性，适合接入 PPO/GRPO 章节。
- [Gnani-Evon 30B-A3B](https://arxiv.org/abs/2610.15371)：混合 Mamba-Transformer MoE 长上下文架构；数理 RL 提升可能伴随语言约定退化，提示 reward 必须 scoped。
- [ProloNg](https://arxiv.org/abs/2610.11592)：长上下文“能读”不等于“能演绎推理”，应增加深度分层测试而不是只报 context length。

**实践清单**：固定 max tokens、停止词、抽取器、量化格式、batch、seed 与 backend；同一模型至少报告短答案/长答案、短上下文/长上下文、greedy/采样三组结果。

## 07-强化学习：信息探索、扩散 RL 与具身安全

- [Info-GRPO](https://arxiv.org/abs/2610.34949)：将长轨迹探索问题从“调 entropy coefficient”转成信息增益/latent diversity 问题。
- [RL Post-Training in Diffusion Transformers Is Activation Steering](https://arxiv.org/abs/2611.26627)：扩散 Transformer 的 RL 后训练可从激活方向变化解释，适合加入“RL 到底改了什么”分析。
- [Constrained Exploration GRPO for multi-talker ASR](https://arxiv.org/abs/2611.22627)：把约束探索用于未知说话人数量的 ASR+diarization。
- 具身安全的 [SAFI](https://arxiv.org/abs/2611.26239v1) 说明拒绝动作应评估“禁止任务是否继续、是否发生物理事故、正常任务是否保留”三项，而不是只看任务成功率。

## 09-计算机视觉：4D 世界、3D 原生生成与视频 KV

- [Plan4D](https://arxiv.org/abs/2611.26516)：可规划的 4D 世界生成，连接视频生成、世界模型和动作规划。
- [Direct3D-V3](https://arxiv.org/abs/2611.26511)：原生体素域扩散 Transformer，减少 latent 设计带来的额外假设。
- [Depth Pro 2](https://arxiv.org/abs/2611.26603)：单目度量深度向视频时间一致性推进。
- [Posterior Matching Distillation](https://arxiv.org/abs/2611.26629)：扩散模型蒸馏从轨迹匹配转向后验匹配。
- [Video DiT 的 2-bit KV Cache](https://arxiv.org/abs/2611.26334)：时序旋转补偿用于极低比特 KV，连接本仓库 15-AI-Infra 的 KV 分层与量化两篇。

**实践清单**：分开报告单帧质量、跨帧一致、规划成功率、推理延迟与 KV 字节；不要用单一 FID 代表世界模型能力。

## 14-具身智能：数据意图、触觉创新、安全拒停、低延迟世界模型

- [HumanCOIN](https://arxiv.org/abs/2611.26434v1)：12,500 小时第一视角操作数据，分为注视、肌电、脑电三层意图代理；缺测必须显式掩码，不能当作零信号。
- [TacInno](https://arxiv.org/abs/2611.26405v1)：学习视觉和已执行动作无法解释的“触觉创新”，部署时不必增加触觉预测头。
- [Teaching VLA to Stop Safely](https://arxiv.org/abs/2611.26239v1)：SAFI 为中途接管构造保持夹持/静止的 fallback target；安全指标拆为禁止任务完成、物理事故、保留任务成功。
- [Fast-JEPA](https://arxiv.org/abs/2611.25927v1)：用目标导向计划与候选整段预测减少递归 rollout，优化 success-latency frontier。

## 16-语音：Audio LLM 可信度与实时性

- [Sound Event Hallucinations](https://arxiv.org/abs/2611.25789)：检测和缓解 Audio LLM 虚构不存在的声音事件。
- [When Sounds Turn Heads](https://arxiv.org/abs/2611.25960)：模型能识别事件却难以准确说出发生时间，提示评测需加入时间定位。
- [AI speech generation and deepfake detection](https://arxiv.org/abs/2611.24993)：语音生成、伪造检测与术语全景综述。
- [Voice-agent latency comparison](https://arxiv.org/abs/2611.19118)：把 Pipecat、LiveKit、GPT-Live 的端到端延迟作为工程指标，而不只比较 WER。
- [Surprise-gated diarization memory](https://arxiv.org/abs/2611.20819)：用惊讶度门控在线说话人记忆，连接 Agent memory 主题。

## 19-推荐系统：生成式推荐的收益与副作用

- [Better Rankers, Worse Retrievers](https://arxiv.org/abs/2611.22838)：生成式推荐 RL 后训练可能提升排序、同时损害召回；必须分层评估召回、排序和最终 utility。
- [Cost-Aware Agentic Feature Optimization](https://arxiv.org/abs/2611.26531)：Agent 自动做 fleet-scale ranking feature engineering，并把成本纳入目标。
- [LLM Embeddings in Production Content Recommendation](https://arxiv.org/abs/2611.26096)：从 session 到线上 serving 的 LLM embedding 全链路。
- [LQ-Rec](https://arxiv.org/abs/2611.25256)：推荐模型部署侧后量化。
- [Rubric Alignment for Search](https://arxiv.org/abs/2611.22503)：评估从 relevance 转向 utility/rubric 对齐。

## 20-多模态大模型：全模态视频与主动空间探索

- [WeMM-Video](https://arxiv.org/abs/2611.26409)：视觉、音频、文本统一的视频理解路线。
- [Learning to Think with Images Faithfully](https://arxiv.org/abs/2611.26199)：自适应数据选择，减少视觉推理“看图说错”。
- [SpatialScout-V2](https://arxiv.org/abs/2611.26177)：VLM Agent 主动探索 3D 场景并定位对象。
- 重点评测应同时报告 OCR、空间关系、时间关系、跨模态幻觉和工具执行成功率。

## 22-图神经网络与知识图谱：图序列化进入推理链

- [Graph Serializations for Reasoning LLMs](https://arxiv.org/abs/2610.22734)：同一知识图谱换不同序列化格式，结构推理表现会明显变化；图序列化不再只是数据预处理，而是动态编排决策。
- 实践上应同时比较三元组文本、邻接列表、路径序列、子图摘要，并报告节点顺序、上下文长度和证据可追溯性。

## 08-优化算法：谱优化器（Muon 家族）

- [Accelerating Muon with Spectral Residual Correction](https://arxiv.org/abs/2611.27077)：AIMuon 保留 Muon 的动量递归，用梯度-动量残差对谱步做修正；GPT-2-small / medium / Qwen3-0.6B 上分别少用 8.98% / 10.05% / 6.49% 步数达到 Muon 的最终验证损失。
- [Federated Learning of Car Aerodynamics Surrogates with Spectral Optimizers](https://arxiv.org/abs/2611.25300)：FedMuon / FedMARS-M 等谱优化器在联邦 CFD 代理模型上的对照——正交化更新对客户端异构更稳。
- 共同机制：对动量矩阵做 Newton–Schulz / 极分解近似（矩阵符号），奇异值被拉平后再按形状缩放。好处是**更新幅度与矩阵形状解耦**，同一学习率可跨层复用；代价是每步多几次矩阵乘。
- 面试口径：Muon 不是"又一个 Adam 变体"，它改的是**更新的几何**（谱域归一化），而非逐元素二阶矩估计。

## 11-时间序列：基础模型的评测与适配

- [Severe but Harmless: Stress-Testing Shift Severity for Frozen Time-Series Forecasters](https://arxiv.org/abs/2611.21562)：冻结 TSFM 在分布漂移下的压力测试，区分"漂移很猛但无害"与真正破坏预测的漂移。
- [Recurrent Domain Incremental Adaptation of Time-Series Foundation Models](https://arxiv.org/abs/2611.24075)：新领域持续到来时的增量适配（而非一次性全量微调）。
- [A Verifier from the Past: Test-Time Compute for Time Series Foundation Models](https://arxiv.org/abs/2611.25171)：把推理期算力用于候选预测的校验。
- [Time Flies When You Parallelise](https://arxiv.org/abs/2611.16934)：线性递归结构在"精度-延迟"帕累托前沿上的取舍。
- [CastWorld](https://arxiv.org/abs/2611.15262)：上下文感知的 agentic 时序预测基准，考核的不只是预测精度。
- 评测要点：TSFM 论文必须报告划分方式（时序 vs 随机）、窗口是否因果、归一化统计量是否只用训练段；否则零样本分数不可比。

## 02-机器学习：表格基础模型与小样本评估

- [Towards Reliable Scaling Laws for Tabular Foundation Models](https://arxiv.org/abs/2611.24214)：表格基础模型的 scaling law 是否可靠，直接决定"要不要继续堆数据/参数"。
- [NVIDIA Kumo Tabular](https://arxiv.org/abs/2611.23001)：开源表格预测模型族，主打精度-效率前沿。
- [Weights & Caches: LLMs Can Program Tabular Foundation Models](https://arxiv.org/abs/2611.20174)：让 LLM 直接生成/改写表格基础模型的计算（权重空间编程）。
- [How Much Do Foundation Models Add to Gradient Boosting on Financial Event Sequences?](https://arxiv.org/abs/2611.18914)：中小规模表格上 FM 相对 GBDT 的真实增量需要严格对照。
- [TabBioMed](https://arxiv.org/abs/2611.23779)：94 个生物医学表格数据集的评测基准（高维、缺失、类别不平衡）。
- 实践要点：小样本 + 多候选方案时必须嵌套交叉验证；在测试集上挑特征/超参是系统性乐观。

## 25-生物信息学：生物基础模型与同源泄漏

- [Calpha: Toward Native Biomolecular Intelligence in a General-Purpose Language Model](https://arxiv.org/abs/2611.20986)：通用语言模型原生处理生物分子，而不是外挂编码器。
- [Trion-1: Unifying Language, Protein Sequence, and Structure with Diffusion Language Models](https://arxiv.org/abs/2610.31215)：用扩散语言模型统一蛋白序列与结构生成。
- [BioMatrix](https://arxiv.org/abs/2606.22138)：覆盖序列、结构、语言三种模态的生物基础模型。
- [AI for Biologists](https://arxiv.org/abs/2611.17015)：生物基础模型的知识边界与 agentic 系统的分工（Annual Review 综述）。
- [Poisoning the corpora of protein design systems](https://arxiv.org/abs/2610.21200)：预训练/检索语料投毒对蛋白设计的影响——数据来源可信度是安全问题。
- 评测要点：蛋白家族内序列高度相似，随机划分近似同源泄漏；需按家族/聚类留出（held-out family）。

## 17-数据科学：预测得准 ≠ 因果对

- [From Forecasting to World Modeling: Can Temporal Foundation Models Recover Causal Response?](https://arxiv.org/abs/2611.15009)（NeurIPS 2026 FMTS workshop）：销量预测得准的时序基础模型，未必能回答价格弹性这类因果问题。
- 实践要点：混淆变量（季节、促销）同时驱动价格与销量；遗漏混淆会让弹性估偏甚至反号。随机化实验或"控制全部后门变量"的回归才接近真值。
- 面试口径：区分**预测目标**（minimize MSE）与**因果目标**（estimate intervention effect），两者所需的假设不同。

## 21-大数据与数仓：向量检索与 LLM 数据代理进入数据库

- 向量索引成为数据库核心能力：[Errpedia](https://arxiv.org/abs/2611.22474)（"你的 exact k-NN 真的 exact 吗"）、[Pelorus](https://arxiv.org/abs/2611.22159)（双曲空间图索引）、[HorizANN](https://arxiv.org/abs/2611.19077)（ghost edges 弹性扩容）、[SIMQ](https://arxiv.org/abs/2611.22079)（单一图索引支持多向量查询）、[UniGraph](https://arxiv.org/abs/2611.20758)（稠密-稀疏混合检索）、[DiskANN beam search 变体](https://arxiv.org/abs/2611.26609)。
- 索引资产与模型换代：[HNSW Migration Under Embedding Model Change](https://arxiv.org/abs/2611.25416) 讨论换 embedding 模型后索引如何迁移修补。
- Text-to-SQL 走向交互式：[AskWise](https://arxiv.org/abs/2611.27474)（执行引导的意图/数据澄清）、[MoL-SQL](https://arxiv.org/abs/2611.22333)（多语言混合基准）、[Adaptive-Elbow schema retrieval](https://arxiv.org/abs/2611.20979)、[Disagreement-Guided Ambiguity Detection](https://arxiv.org/abs/2611.21645)。
- LLM 进入查询执行路径：[Online Adaptive LLM-based Semantic Filtering](https://arxiv.org/abs/2611.24518)、[Cascadeability 实证研究](https://arxiv.org/abs/2611.23898)。
- Agent 与数据平台：[DataTrace](https://arxiv.org/abs/2611.18926)（证据锚定的根因定位基准）、[KaleidoKV](https://arxiv.org/abs/2611.19253)（离线 RAG 推理的 KV 复用）、[Read Boundaries in Agent Memory](https://arxiv.org/abs/2611.19264)（记忆读取一致性）。
- 工程要点：向量检索验收必须报 **recall@k**，而不是"返回了 k 条"；量化（PQ）与 IVF 的 nprobe 都会带来静默漏检，且换 embedding 模型等于换索引资产。

## 10-自然语言处理：结构化抽取与解码方式

- 结构化输出：[SheetAlign](https://arxiv.org/abs/2611.26586)（表格结构与单元格对齐）、[ChronoDossier](https://arxiv.org/abs/2611.26552)（长文档档案的事实组织）。
- 评测与 Agent 化：[AutoRAGBench](https://arxiv.org/abs/2611.26377)（评测 LLM Agent 自动搭 RAG 系统）、[STARK](https://arxiv.org/abs/2611.26566)（会学习与记忆的个性化 Agent）。
- 解码侧：[dLoop](https://arxiv.org/abs/2611.26604)（低推理预算扩散语言模型）、[MTP 投机解码](https://arxiv.org/abs/2611.26508)（多 token 预测做草稿）。
- 验收口径：抽取任务必须报 **entity-level P/R/F1**；边界错一个 token，token 准确率仍可能 90%+，但实体整条判错。

## 24-信号处理：神经编解码与量化前端

- [Binarized Neural Vocoder](https://arxiv.org/abs/2611.22593)：声码器压到二值权重/极低比特。
- [21Codec](https://arxiv.org/abs/2611.24094)：解码端可控音色的编解码器。
- [ProSing](https://arxiv.org/abs/2611.19223)：零样本唱法转换。
- [Spatial Audio LALM](https://arxiv.org/abs/2611.18112)：任意通道数压成单一 token 流的空间音频理解。
- DSP 账本仍然适用：**比特率 × 采样率 = 存储/带宽**，SQNR 衡量失真；μ-law 压扩对动态范围大的语音更友好（合成信号上 8/6/4 bit 分别约 +1.6/+1.4/+1.6 dB）。

## 23-统计学：有限样本保证——conformal、anytime-valid 与多重检验

- [Smoothed Conformal Testing with Small Calibration Sets](https://arxiv.org/abs/2611.27315)：校准集很小时 conformal 检验的平滑修正。
- [Realized versus Population Reliability: Anytime-Valid Self-Consistency Certification under Correlated Reasoning](https://arxiv.org/abs/2611.26592)：把随时可停（anytime-valid）的可靠性证书用到 LLM 推理自一致性上——统计保证与推理模型评测的交汇点。
- [Combining Past Experimental Data for Efficient Estimation: A Shrinkage Approach](https://arxiv.org/abs/2611.27655)：A/B 实验借助历史数据做收缩估计。
- [On the Validity of Fisher Randomization Tests under the Weak Null](https://arxiv.org/abs/2611.24821)；[A Local False Discovery Rate Framework for Compound p-values](https://arxiv.org/abs/2611.24555)：随机化检验与多重检验的现代口径。
- 实践要点：conformal 只保证**交换性下的边际覆盖率**；协变量漂移通常仍近似成立，但标签分布变化会让覆盖率明显失守。
