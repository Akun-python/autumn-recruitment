# 📡 其他模块前沿技术补充 · 2026-11

> 本页把 2026-11-16～20 arXiv 最新批次映射到仓库模块。它是面试/选题导航，不替代论文复现；数字只在已打开的 arXiv 摘要中使用。

## 04-LLM大模型：推理设置、长程推理与 Mamba-MoE

- [Inference for Reasoning Models](https://arxiv.org/abs/2611.10845)：最大生成长度、答案抽取、量化、batch、attention backend、cache 都会改变结果；**评测配置本身是实验变量**。
- [Info-GRPO](https://arxiv.org/abs/2610.34949)：长思维链 GRPO 的探索-收敛张力，用 latent seed / 轨迹互信息改善多样性，适合接入 PPO/GRPO 章节。
- [Gnani-Evon 30B-A3B](https://arxiv.org/abs/2610.15371)：混合 Mamba-Transformer MoE 长上下文架构；数理 RL 提升可能伴随语言约定退化，提示 reward 必须 scoped。
- [ProloNg](https://arxiv.org/abs/2610.11592)：长上下文“能读”不等于“能演绎推理”，应增加深度分层测试而不是只报 context length。

**实践清单**：固定 max tokens、停止词、抽取器、量化格式、batch、seed 与 backend；同一模型至少报告短答案/长答案、短上下文/长上下文、greedy/采样三组结果。

## 07-强化学习：信息探索、扩散 RL 与具身安全

- [Info-GRPO](https://arxiv.org/abs/2610.34949)：将长轨迹探索问题从“调 entropy coefficient”转成信息增益/latent diversity 问题。
- [RL Post-Training in Diffusion Transformers Is Activation Steering](https://arxiv.org/abs/2611.26627)：扩散 Transformer 的 RL 后训练可从激活方向变化解释，适合加入“RL 到底改了什么”分析。
- [Constrained Exploration GRPO for multi-talker ASR](https://arxiv.org/abs/2611.22627)：把约束探索用于未知说话人数量的 ASR+diarization。
- 具身安全的 [SAFI](https://arxiv.org/abs/2611.26239v1) 说明拒绝动作应评估“禁止任务是否继续、是否发生物理事故、正常任务是否保留”三项，而不是只看任务成功率。

## 09-计算机视觉：4D 世界、3D 原生生成与视频 KV

- [Plan4D](https://arxiv.org/abs/2611.26516)：可规划的 4D 世界生成，连接视频生成、世界模型和动作规划。
- [Direct3D-V3](https://arxiv.org/abs/2611.26511)：原生体素域扩散 Transformer，减少 latent 设计带来的额外假设。
- [Depth Pro 2](https://arxiv.org/abs/2611.26603)：单目度量深度向视频时间一致性推进。
- [Posterior Matching Distillation](https://arxiv.org/abs/2611.26629)：扩散模型蒸馏从轨迹匹配转向后验匹配。
- [Video DiT 的 2-bit KV Cache](https://arxiv.org/abs/2611.26334)：时序旋转补偿用于极低比特 KV，连接本仓库 15-AI-Infra 的 KV 分层与量化两篇。

**实践清单**：分开报告单帧质量、跨帧一致、规划成功率、推理延迟与 KV 字节；不要用单一 FID 代表世界模型能力。

## 14-具身智能：数据意图、触觉创新、安全拒停、低延迟世界模型

- [HumanCOIN](https://arxiv.org/abs/2611.26434v1)：12,500 小时第一视角操作数据，分为注视、肌电、脑电三层意图代理；缺测必须显式掩码，不能当作零信号。
- [TacInno](https://arxiv.org/abs/2611.26405v1)：学习视觉和已执行动作无法解释的“触觉创新”，部署时不必增加触觉预测头。
- [Teaching VLA to Stop Safely](https://arxiv.org/abs/2611.26239v1)：SAFI 为中途接管构造保持夹持/静止的 fallback target；安全指标拆为禁止任务完成、物理事故、保留任务成功。
- [Fast-JEPA](https://arxiv.org/abs/2611.25927v1)：用目标导向计划与候选整段预测减少递归 rollout，优化 success-latency frontier。

## 16-语音：Audio LLM 可信度与实时性

- [Sound Event Hallucinations](https://arxiv.org/abs/2611.25789)：检测和缓解 Audio LLM 虚构不存在的声音事件。
- [When Sounds Turn Heads](https://arxiv.org/abs/2611.25960)：模型能识别事件却难以准确说出发生时间，提示评测需加入时间定位。
- [AI speech generation and deepfake detection](https://arxiv.org/abs/2611.24993)：语音生成、伪造检测与术语全景综述。
- [Voice-agent latency comparison](https://arxiv.org/abs/2611.19118)：把 Pipecat、LiveKit、GPT-Live 的端到端延迟作为工程指标，而不只比较 WER。
- [Surprise-gated diarization memory](https://arxiv.org/abs/2611.20819)：用惊讶度门控在线说话人记忆，连接 Agent memory 主题。

## 19-推荐系统：生成式推荐的收益与副作用

- [Better Rankers, Worse Retrievers](https://arxiv.org/abs/2611.22838)：生成式推荐 RL 后训练可能提升排序、同时损害召回；必须分层评估召回、排序和最终 utility。
- [Cost-Aware Agentic Feature Optimization](https://arxiv.org/abs/2611.26531)：Agent 自动做 fleet-scale ranking feature engineering，并把成本纳入目标。
- [LLM Embeddings in Production Content Recommendation](https://arxiv.org/abs/2611.26096)：从 session 到线上 serving 的 LLM embedding 全链路。
- [LQ-Rec](https://arxiv.org/abs/2611.25256)：推荐模型部署侧后量化。
- [Rubric Alignment for Search](https://arxiv.org/abs/2611.22503)：评估从 relevance 转向 utility/rubric 对齐。

## 20-多模态大模型：全模态视频与主动空间探索

- [WeMM-Video](https://arxiv.org/abs/2611.26409)：视觉、音频、文本统一的视频理解路线。
- [Learning to Think with Images Faithfully](https://arxiv.org/abs/2611.26199)：自适应数据选择，减少视觉推理“看图说错”。
- [SpatialScout-V2](https://arxiv.org/abs/2611.26177)：VLM Agent 主动探索 3D 场景并定位对象。
- 重点评测应同时报告 OCR、空间关系、时间关系、跨模态幻觉和工具执行成功率。

## 22-图神经网络与知识图谱：图序列化进入推理链

- [Graph Serializations for Reasoning LLMs](https://arxiv.org/abs/2610.22734)：同一知识图谱换不同序列化格式，结构推理表现会明显变化；图序列化不再只是数据预处理，而是动态编排决策。
- 实践上应同时比较三元组文本、邻接列表、路径序列、子图摘要，并报告节点顺序、上下文长度和证据可追溯性。
