## 0. 本期五条判断

1. **稀疏 MoE 的大规模异步 RL 正在取代「堆数据」成为主叙事**：Beam（501.3B 总参 / 23.4B 激活）+ 10.5K 卡异步 RL + 1M 上下文 + FP8/NVFP4 + 投机解码 drafter，是一条完整的「模型-硬件-服务」协同设计样本。
2. **推理系统的关键词从「省显存」变成「分层 + 预测」**：KV 页、专家页、索引页都在被同一套思路（页表 / 热度缓存 / 预取 / 压缩）重构。
3. **RSI 从 LLM 扩散到视觉、机器人、后训练全流程**，并且出现了「观测侧进化」这个新旋钮——平台期可能是观测耗尽，而不是能力耗尽。
4. **Agent 的竞争点转向「记忆结构」与「技能库自进化」**，不再是单纯的工具调用能力。
5. **低比特进一步下探**：FP4（NVFP4 block-16 + FP8 scale）与 2:4 结构化稀疏进入硬件原生支持阶段，量化考点需要从 INT8/INT4 扩展到 FP4/稀疏。

## 8. 检索方法与局限
