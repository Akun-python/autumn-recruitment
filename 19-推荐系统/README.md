# 🎯 19-推荐系统：召回 / 排序 / CTR 预估 / 冷启动 / 多目标 / 搜广推

> 推荐系统（搜索/推荐/广告，俗称**搜广推**）是算法岗招聘量最大的方向之一。
> 本模块从「一条推荐链路」入手，覆盖**评估指标（AUC/GAUC/NDCG）、协同过滤、矩阵分解、
> 双塔召回与向量检索、CTR 预估（LR→FM→DeepFM/GBDT+LR）、排序特征与采样、
> 冷启动与多目标（ESMM/MMoE）、工业流程与面试八股**，全部可执行、含断言与可视化。
>
> 面向秋招画像：**推荐/搜索/广告算法工程师、增长算法、商业化算法** 岗位。
> 前置衔接：02-机器学习（LR/GBDT/特征工程）、03-深度学习（DNN/Embedding）、
> 17-数据科学（AB 实验/评估）、18-数据分析（业务指标/用户分层）。

> 🖼️ 教学 notebook 全部基于 numpy/pandas/matplotlib/scipy/sklearn，自包含可执行，
> 含断言与数值对照（手写 vs 库实现）；绘图统一中文字体并显式 `plt.show()`。

## 知识地图（面试考察的八块）

```
推荐系统考点
├── 1. 链路与评估  召回→粗排→精排→重排→AB · AUC/GAUC/NDCG@K/HR@K/Recall@K
├── 2. 协同过滤    UserCF / ItemCF · 余弦/皮尔逊相似度 · Top-N 推荐
├── 3. 矩阵分解     Funk-SVD（SGD+偏差+正则）· 截断 SVD · embedding 语义

├── 5. CTR 预估     LR → LR+交叉 → FM（pair 项+梯度）→ GBDT+LR → Wide&Deep/DeepFM
├── 6. 排序工程    特征体系 · 特征交叉 · 负样本采样 · Pointwise/Pairwise/Listwise

```

## 学习路线（推荐顺序）

1. **搭框架（00）**：推荐链路五段 + 评估指标手写（AUC/GAUC/NDCG）✅

## 面试高频题型（详见 [高频面试题.md](高频面试题.md)）

- **评估类**：AUC 物理意义、GAUC 为什么更贴近推荐、NDCG 位置加权、离线评估三偏差
- **召回类**：双塔为什么适合召回、负采样策略、ANN 索引（HNSW/IVF/PQ）、多路召回合并
- **排序类**：FM pair 项推导、GBDT+LR 原理、DeepFM 结构、Pointwise vs Pairwise
- **冷启动类**：用户/物品冷启动方案、EE（探索-利用）、信息茧房
- **多目标类**：ESMM 乘法关系、MMoE 门控、任务冲突与负迁移
- **工业类**：链路各层职责、位置偏差/曝光偏差、特征穿越、AB 实验与放量
