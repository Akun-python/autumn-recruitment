## 面试高频题型（详见 [高频面试题.md](高频面试题.md)）

- **对齐类**：InfoNCE 公式与推导、温度 τ 的作用、CLIP 为什么能 zero-shot、对比学习的正负样本
- **架构类**：ViT 流程、CNN vs ViT、Q-Former 是什么、LLaVA 投影层、视觉 token 数量权衡
- **训练类**：三阶段训练、为什么冻结、视觉编码器选择（CLIP ViT vs 通用 ViT）、数据配比
- **生成类**：扩散前向/反向公式、训练目标、CFG 采样、SD 在潜空间扩散、DiT
- **视频类**：帧采样、时间池化 vs 时序注意力、长视频 token 爆炸、音视频对齐
- **评估类**：检索 Recall@K、CLIP score、FID、MMBench/MMMU、评测五大陷阱
