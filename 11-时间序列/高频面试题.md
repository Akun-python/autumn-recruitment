## 1. 基础与平稳性

> 📍 教学 → `00-基础与平稳性.ipynb`

- [ ] 时间序列三要素：趋势/季节/周期/噪声；加法与乘法模型
- [ ] 弱平稳三条件：均值恒定、方差恒定、协方差只依赖滞后
- [ ] 强平稳 vs 弱平稳：联合分布不变 vs 一、二阶矩稳定
- [ ] 随机游走为什么非平稳：方差随 t 线性增长；差分后变白噪声
- [ ] 平稳化手段：差分（去趋势/随机游走）、季节差分（去周期）、对数（稳方差）
- [ ] ADF 检验：原假设有单位根；t 统计量越负越拒绝
- [ ] ACF 定义与估计：ρ(k)=γ(k)/γ(0)；去均值点积/方差
- [ ] PACF 定义：逐阶回归取 x_{t-k} 的系数
- [ ] 白噪声三特征 + Ljung-Box：Q=n(n+2)Σρ²/(n-k) ~ χ²(h)
- [ ] 95% ACF 置信带 ±1.96/√n；越界提示自相关
- [ ] 为什么建模前必须平稳（参数无意义 / 预测回归均值）
- [ ] 差分阶数怎么定：ADF 不过就再差（d≤2）

## 2. ARMA 与 ARIMA

> 📍 教学 → `01-ARMA与ARIMA.ipynb`

- [ ] AR(p)/MA(q) 公式与含义：历史观测 vs 历史误差回归
- [ ] ARIMA(p,d,q) = 差 d 阶再做 ARMA；SARIMA 加季节阶
- [ ] AR(1) 平稳条件 |φ|<1；AR(p) 特征根在单位圆外
- [ ] 为什么 MA 一定平稳：有限记忆
- [ ] ACF/PACF 定阶表：AR→PACF 截尾、MA→ACF 截尾、ARMA 都拖尾
- [ ] AR 怎么估计：OLS；MA 怎么估计：反解误差迭代/网格/MLE
- [ ] AIC/BIC 公式与差异：-2lnL+2k vs -2lnL+k·ln n（BIC 更严）
- [ ] 预测怎么外推：AR 递归代入；长期预测收敛均值（回归均值）
- [ ] 预测区间为什么变宽：误差逐期累积 σ√h
- [ ] 残差诊断：Ljung-Box 白噪声检验
- [ ] ARIMA 的局限：线性、单变量、长序列/非线性不行
- [ ] 什么时候升级 ML/DL：非线性、多变量、外生特征、长依赖
