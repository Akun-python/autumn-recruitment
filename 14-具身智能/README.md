# 🤖 14-具身智能：从「看懂的 AI」到「会动手的 AI」

> 🖼️ 配图：6 篇教学 notebook 均配有 Wikimedia Commons 网络示意图（机器人运动学/点云/路径规划/VLA 架构/sim2real/工业机器人，见 `教学/images/web_*`，标注出处与许可）＋本地 matplotlib 演示图（`emb*`）。
>
> 📖 深化：每篇在「面试考点」前新增 **「模型详解（面试深度）」** 大节——机器人学（位姿三件套/齐次变换/DH 正逆运动学/雅可比/动力学）、感知（PointNet/PointPillars/SAM/BEVFormer/Occupancy/SLAM）、规划控制（A*/RRT/样条/PID/MPC/CHOMP/阻抗/行为树）、VLA（RT-1/RT-2/PaLM-E/OpenVLA/ACT/Diffusion Policy/VQ-BET/π0/GR00T 档案卡 + VQ-VAE/DDPM/流匹配公式）、Sim2Real（物理引擎/域随机化/系统辨识/数据配方）与全章模型档案总表，全部 LaTeX 公式 + 面试记忆点。

> 具身智能（Embodied AI）= **感知（看懂环境）+ 决策/规划（想好动作）+ 控制（动起来）+ 学习（越做越强）** 的闭环，
> 是大模型从"聊天"走向"干活"的关键方向（RT-2 / OpenVLA / π0 / GR00T / 宇树 / 智元 等均属此赛道）。
>
> 面向秋招画像：**具身智能 / 机器人算法 / 机器人学习 / 自动驾驶** 岗位。与 09-计算机视觉、07-强化学习、04-LLM 大模型、08-优化算法 直接衔接。
>
> 学完本模块，你应该能回答：**齐次变换矩阵为什么能同时表达旋转和平移？正逆运动学解决什么问题？
> VLA 模型把视觉、语言、动作怎么拼在一起？仿真数据怎么迁移到真机（sim2real）？**

## 🗺️ 建议学习路线

```
第 1 遍（打地基，1 周）：00 → 01 → 02 → 03 → 04 → 05
   （00-02 是机器人硬核基础，03-04 是 2023 后最热的 VLA/数据方向）
第 2 遍（对着已有章节用）：
   09-计算机视觉       → 翻 01 感知（检测/分割/点云）
   07-强化学习         → 翻 02 控制（MPC/策略）、04 sim2real（域随机化）
   04-LLM大模型        → 翻 03 VLA（多模态对齐、动作生成）
第 3 遍（考前速查）：只看 05 八股 + 每篇「面试考点」小节
```
