## 1️⃣ 序列与格式（10 题）

1. **FASTA 与 FASTQ 的区别？**
   FASTA：`>id` 描述行 + 序列（多行拼接）；FASTQ：`@id` + 序列 + `+` + 质量字符串（Phred 编码）。

2. **Phred 质量 Q30 的含义？**
   碱基错误概率 $10^{-30/10}=0.1\%$，即千分之一出错；Q20=1%，Q40=0.01%。

3. **质量值怎么编码成 ASCII？**
   Sanger/Illumina 1.8+：`chr(Q+33)`，如 Q30 → 字符 `'?'`（63）。

4. **DNA 互补配对规则？**
   A-T、C-G；RNA 为 A-U。反向互补 = 倒序 + 逐碱基互补。

5. **为什么关心 GC 含量？**
   影响 Tm（退火温度）、二代测序覆盖均匀性、物种鉴定与基因组特征描述。

6. **k-mer 是什么？用在哪？**
   长度为 k 的连续子串；用于组装（de Bruijn 图）、比对 seed、宏基因组指纹、序列距离估计。

7. **测序深度与覆盖度的区别？**
   深度 = 平均每个碱基被测到的次数（如 30×）；覆盖度 = 至少被读到 1 次的碱基比例（如 95%）。

8. **读长一般多长？**
   二代短读 100-150bp 常见；三代长读 10kb+（PacBio/ONT），利于跨重复区组装。

9. **为什么要去接头（adapter trimming）？**
   短片段测序会读到接头序列，不去除会污染比对与组装、导致错误变异/基因调用。

10. **单端 vs 双端测序？**
    双端（paired-end）读同一片段两端，可确定插入片段、提高比对唯一性与组装质量。

## 2️⃣ 序列比对（10 题）

11. **全局比对与局部比对的区别？**
    全局（Needleman-Wunsch）强制全长对齐，适合同源全长比较；局部（Smith-Waterman）找最相似子片段，适合找结构域/跨物种同源区。

12. **Needleman-Wunsch 算法思想？**
    动态规划：`F(i,j)=max(F(i-1,j-1)+s, F(i-1,j)+gap, F(i,j-1)+gap)`，回溯 DP 路径得最优对齐。

13. **Smith-Waterman 与 NW 的区别？**
    矩阵初值 0（不累加空位）、负值截断为 0、从最大分值回溯到 0，得到局部最优片段。

14. **线性与仿射空位罚分？**
    线性每个空位 -g；仿射 = 开启罚分（open）+ 延伸罚分（extend），更贴近真实 indel 事件（一段空位是一个事件）。

15. **BLOSUM62 是什么？**
    蛋白替换打分矩阵，基于保守块（blocks）统计，62 表示 62% 一致度的块；比 PAM 更常用。

16. **比对的复杂度？**
    NW/SW 精确比对 O(n×m) 时间与空间；长序列靠 seed-extend 启发式（BLAST）或索引（FM-index）。

17. **为什么蛋白比对比 DNA 比对更敏感？**
    密码子简并使同义突变不改变氨基酸，蛋白序列更保守、信号更清晰。

18. **Profile HMM 是什么？**
    用隐马尔可夫模型刻画多序列比对的位点保守模式（match/insert/delete），HMMER 用于搜索序列家族。

19. **多序列比对工具？**
    Clustal（经典）、MUSCLE、MAFFT（快）；用于建进化树、找保守区、设计引物。

20. **比对结果怎么解读？**
    一致性与覆盖度都要看：100% identity 但只覆盖 30% 的基因不完整，可能是部分同源。

## 3️⃣ 搜索与 BLAST（10 题）

21. **BLAST 的基本流程？**
    查询拆 k-mer → 在数据库索引中找 seed 命中 → 双方向延伸成 HSP → 显著性统计（Karlin-Altschul）→ 报告。

22. **E-value 是什么？**
    随机数据库中期望出现得分 ≥ 当前命中的次数；越小越显著（E<0.05 常见阈值）。

23. **E-value 与 p-value 的区别？**
    p 是单次比对的显著性；E 是整库搜索的期望数，**随数据库大小增长**——同一比对在更大库里 E 更大。

24. **identity 与 coverage 的区别？**
    identity = 对齐区内一致碱基比例；coverage = 查询序列被覆盖的比例；两者都高才可信。

25. **seed 长度怎么选？**
    短 seed 假阳性多、敏感度高；长 seed 特异性高但可能漏远亲；DNA 常用 k=11，蛋白 3aa。

26. **HSP 是什么？**
    High-scoring Pair，seed 延伸得到的高分片段对；BLAST 报的是显著 HSP 而非整条比对。

27. **大基因组用什么索引？**
    FM-index（BWA/bowtie2）基于 BWT，内存小；泛基因组时代也常用 k-mer 索引（如 minimap2 的 sketch）。

28. **短读/长读比对工具怎么选？**
    短读：BWA-MEM、bowtie2；长读：minimap2（声学/长读都支持）；蛋白质：DIAMOND、BLASTp。

29. **怎么降低假阳性？**
    收紧 E-value、要求高质量比对（MAPQ）、覆盖度过滤、多序列交叉验证、人工检查。

30. **BLAST 与 BLAT/minimap2 的区别？**
    BLAST 允许 gapped 精确统计；BLAT 偏快速近似；minimap2 针对长读/组装比对做了优化。

## 4️⃣ 基因结构与表达（10 题）

31. **ORF 是什么？怎么找？**
    开放阅读框：从 ATG 到终止密码子（TAA/TAG/TGA）的连续编码区；6 框扫描 + 长度/统计过滤。

32. **6 框翻译是什么？**
    正链 3 个阅读框（偏移 0/1/2）+ 反向互补链 3 框，共 6 种读法。

33. **外显子与内含子？**
    外显子编码保留在 mRNA；内含子在剪接中去除；真核基因注释常用转录组证据辅助。

34. **RNA-seq 标准流程？**
    质控 → 比对（STAR/Hisat2）→ 定量（featureCounts）→ 归一化 → 差异表达 → 功能富集。

35. **TPM 与 RPKM/FPKM 的区别？**
    TPM 先算 RPK（长度校正）再按占比归一、总和恒 1e6；跨样本相对丰度更可比。FPKM 是 RPKM 的 paired-end 版本。

36. **为什么 RNA-seq 要归一化？**
    测序深度不同、基因长度不同，原始计数不可直接跨样本比较。

37. **差异表达用什么统计模型？**
    DESeq2/edgeR 用负二项分布建模计数（overdispersion），limma 用经验贝叶斯线性模型；都做 FDR 校正。

38. **log2FC 与 padj 怎么判显著？**
    |log2FC| ≥ 1（≥2 倍变化）且 BH-FDR 校正后 padj < 0.05。

39. **火山图怎么看？**
    x = log2(倍数变化)，y = -log10(p)；右上显著上调、左上显著下调，越靠上越显著。

40. **GO 与 KEGG 富集用什么检验？**
    超几何检验（或 Fisher 精确检验），看"某通路基因在差异基因中是否显著富集"，同样需 FDR 校正。

## 5️⃣ 变异与进化（10 题）

41. **SNP/Indel/SV/CNV 区别？**
    SNP 单碱基替换；Indel 小插入缺失（可移码）；SV 大片段结构变异（缺失/重复/倒位/易位）；CNV 拷贝数变化。

42. **VCF 的 8 个固定列？**
    CHROM POS ID REF ALT QUAL FILTER INFO；样本列可选（GT/DP/GQ）。

43. **等位基因频率怎么算？**
    AF = 变异等位基因拷贝数 / 总等位基因数（2N）；MAF 取 A 与 a 中较小者。

44. **基因型 GT 怎么看？**
    0/0 纯合参考、0/1 杂合、1/1 纯合变异；`0|1` 表示定相（来自哪个亲本）。

45. **Hardy-Weinberg 平衡？**
    p² + 2pq + q² = 1；严重偏离提示选择、群体分层、测序错误或拷贝数异常。

46. **UPGMA 与 NJ 的区别？**
    UPGMA 假设分子钟（所有谱系速率一致），树为超度量；NJ 用净分化速率矫正，允许速率不等，实际更常用。

47. **bootstrap 支持率？**
    对 MSA 列重采样（如 1000 次）重建树，统计节点重现频率；>70% 通常可信，>95% 强支持。

48. **分子钟是什么？**
    序列差异近似正比于分化时间；用于定年需校准（化石/已知事件），且速率可能不均。

49. **p-distance 与 Jukes-Cantor 的区别？**
    p-distance 是直接差异比例；JC 校正多重替换（饱和），$d=-0.75\ln(1-4p/3)$。

50. **进化树怎么读？**
    分支长度=差异量；节点=共同祖先；支持率=置信度；姐妹群=最近共同祖先关系。

## 6️⃣ 宏基因组与群落（10 题）

51. **宏基因组 vs 16S 扩增子？**
    16S 只扩增细菌/古菌 16S rRNA 基因片段，便宜、看物种组成；WGS 宏基因组测全部 DNA，可同时看物种+功能+菌株。

52. **OTU 与 ASV 的区别？**
    OTU 按 97% 相似度聚类（阈值主观）；ASV 按单碱基精确去噪（DADA2），可跨研究比较、不依赖聚类阈值。

53. **α 多样性是什么？**
    单样本内部多样性：Shannon（熵）、Simpson（集中度/1-D）、Chao1（物种数估计）、Observed species。

54. **β 多样性是什么？**
    样本间组成差异：Bray-Curtis（丰度加权）、Jaccard（有无）、UniFrac（含系统发育信息）。

55. **PCoA 与 PCA/NMDS 的区别？**
    PCA 对数据矩阵做特征分解（隐含欧氏距离）；PCoA 直接对任意距离矩阵做特征分解；NMDS 只保留距离秩，对非线性关系更稳健。

56. **PERMANOVA 是什么？**
    置换多元方差分析：比较组间/组内距离，通过置换分组标签检验"分组是否显著解释差异"（adonis2/vegan）。

57. **稀疏曲线读什么？**
    x=测序深度，y=观察物种数；曲线平台期表示深度足够，未平台则更多测序会带来更多物种。

58. **抽平（rarefaction）有什么用？**
    把样本抽到相同深度再比 α/β 多样性，消除测序深度差异带来的偏差。

59. **F/B 比值是什么？**
    厚壁菌门/拟杆菌门比，常被关联代谢健康——但结论争议大、混杂因素多，需谨慎解读。

60. **宏基因组功能注释怎么做？**
    组装 → 基因预测 → DIAMOND 比对到 KEGG/eggNOG/CAZy/GO → 丰度定量 → 通路富集（超几何检验）。

## 7️⃣ 实战流程（12-14 篇，真实数据 + 专业包）

61. **测序数据质控做什么？**
    fastp/Qiime2 cutadapt：去接头、滑窗修剪低质量（如 4bp 窗均 Q<15 截断）、滤短（<50bp）、
    去 N、去重复；报告 GC 含量、Q20/Q30 比例、错误率曲线。

62. **de Bruijn 图组装原理？**
    reads 切 k-mer，前缀×(k-1) 连后缀×(k-1) 建图，覆盖度高的路径为真实序列；
    测序错误产生低覆盖分支（死胡同），靠覆盖度阈值与 tip-removal 修剪。

63. **N50 / L50 是什么？**
    contig 从长到短累计，长度达到总长一半时的 contig 长 = N50（越大越连续）；
    该条在序列中的序号 = L50。宏基因组混合物种，N50 通常远低于单菌。

64. **Prodigal/pyrodigal 怎么做基因预测？**
    扫描 6 框 ORF，用密码子偏好（尤其第 3 位 GC3）、起始密码子频率、GC 含量、
    长度与重叠惩罚打分；`meta` 模式无需训练，适合宏基因组混合序列。

65. **为什么起始密码子偏好很重要？**
    原核生物绝大多数基因以 ATG 起始（少量 GTG/TTG），同义密码子使用偏好是区分
    编码/非编码区的最强信号之一。

66. **功能注释"同源传递"原理？**
    预测蛋白 → DIAMOND/BLAST 比对参考库（KEGG/eggNOG/COG/GO）→ 最佳命中（E 值/覆盖度阈值）
    → 把数据库中已知功能"传递"给新序列；注释质量取决于库覆盖率与比对确实性。

67. **Kraken2 物种分类原理？**
    参考基因组（含分类学树）切 k-mer 建索引；reads 逐 k-mer 精确匹配，沿 LCA（最低共同祖先）
    树汇总到分类节点，命中最多的节点即为物种归属。

68. **k-mer 指纹做物种鉴定靠谱吗？**
    对物种特异的 k-mer 命中有高区分度；缺陷是同源保守区共 k-mer（不同物种都命中）、
    应变异与测序错误降低命中；需 LCA 与覆盖度联合校正。

69. **宏基因组 α 多样性用哪些包/指标？**
    scikit-bio / QIIME2：Shannon、Chao1、Simpson、Observed OTU；抽平（rarefaction）后再算可消除深度偏差。

70. **宏基因组 β 多样性与组间检验怎么选？**
    Bray-Curtis（丰度加权）/Jaccard/UniFrac → PCoA 可视化；组间差异用 PERMANOVA（置换检验，
    不假设正态，p 来自 999+ 次分组标签置换）——比 t 检验更适合高维组成数据。

71. **样本量多少够做 PERMANOVA？**
    每组 ≥5-10 个为宜：小样本（如每组 3 个）置换空间小、F 分布极端，
    显著性容易被稀释（p 值不稳健）。设计实验要留足生物学重复。

72. **为什么宏基因组要先组装再注释，而不是直接比对 reads？**
    组装能恢复"基因上下文"（共线性、操纵子、菌株结构），提升功能注释的
    连续性；代价是组装错误（嵌合体、缺断裂）。也可用 reads 直接分组装（k-mer 分类）。
