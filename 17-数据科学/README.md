## 面试高频题型（详见 [高频面试题.md](高频面试题.md)）

- **统计推断类**：CLT 与标准误、置信区间与 p 值的经典误解、检验方法选型（t/z/卡方/ANOVA）、功效与样本量、多重比较修正
- **AB 实验类**：样本量手算、AA/SRM、连续监控与 peeking、CUPED 原理与方差缩减、GAUC、辛普森悖论
- **因果推断类**：相关 vs 因果、潜在结果与 ATE/ATT、PSM/IPTW/DID 手撕、RDD/IV 直觉、uplift 建模、反事实
- **业务指标类**：北极星指标拆解、漏斗/留存/同期群、指标口径、埋点质量、长周期实验与实验平台治理

## 验收标准

- [ ] 能口述统计推断全流程：总体 → 抽样 → 统计量 → CLT → 假设检验 → p 值 → 结论，并讲清 p 值 / 置信区间 / 功效的三大经典误区
- [ ] 能推导双样本 t 统计量与两样本比较的样本量公式，说清 n 与 α、β、MDE、σ 的关系
- [ ] 能完整设计一个 AB 实验：指标 → 样本量 → 分流 → AA/SRM 校验 → 显著性分析 → CUPED 降方差 → 结论与上线决策
- [ ] 能识别并解释 SRM、连续监控（peeking）、辛普森悖论、p-hacking、幸存者偏差等实验与分析陷阱
- [ ] 能手写 PSM（倾向得分 + 最近邻匹配 + 平衡性检验）与 DID（倍分法估计量），并用模拟数据验证
- [ ] 能讲清潜在结果框架、ATE/ATT、SUTVA、混淆/后门，并区分因果任务与预测任务（uplift vs 分类）
- [ ] 高频面试题清单 70+ 题：每题不看资料能写出公式、讲出流程与应用场景
- [ ] 手撕清单 5 题（t 检验 / 样本量 / DID / PSM / CUPED）可现场完成并给出正确结论
