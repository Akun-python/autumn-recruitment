## 1. 统计基础与推断

> 📍 教学 → 00-统计推断与假设检验.ipynb

- [ ] 描述统计：均值/中位数/众数、方差/标准差、偏度/峰度；什么时候中位数比均值更合适（长尾/离群）
- [ ] 分位数与箱线图：IQR 定义、1.5×IQR 离群判定、分位数的插值计算
- [ ] 抽样分布与标准误：SE = σ/√n 的推导直觉；标准误与标准差的区别
- [ ] 中心极限定理（CLT）：陈述、成立条件（iid、有限方差）、对重尾分布的表现；为什么实际数据常"近似正态"
- [ ] 点估计与区间估计：MLE 直觉、无偏/一致/有效；置信区间的频率学派正确解释
- [ ] 95% 置信区间的常见误解（它不是"真值有 95% 概率落在这个区间"）
- [ ] z 检验 vs t 检验：σ 已知/未知、样本量、正态性——各自适用条件与自由度
- [ ] 单样本 / 双样本 / 配对检验的选型与自由度计算
- [ ] p-value 的数学定义与三大误解（不是 H0 为真的概率、不度量效应大小、不保证可复现）
- [ ] 第一类/第二类错误：α、β、显著性水平与检验功效的权衡
- [ ] 检验功效 power = 1−β：与 α、样本量、效应量、方差的关系；功效不足的后果
- [ ] 卡方检验：独立性/拟合优度/齐性检验，期望频数 ≥5 的近似条件
- [ ] ANOVA：组间/组内方差、F 统计量、与 t 检验的关系（两组时 F = t²）、事后检验（Tukey）
- [ ] 多重比较问题：为什么两两检验会膨胀假阳性；Bonferroni 与 BH-FDR 的原理对比与取舍
- [ ] bootstrap：原理、与解析方法（t 检验）的对比、常见应用场景
- [ ] 正态性检验（Shapiro-Wilk、QQ 图）与数据变换（log、Box-Cox）；大样本下能否放弃正态假设
- [ ] 效应量与 p 值的关系：p < 0.05 但效应很小意味着什么；统计显著 vs 业务显著
- [ ] 为什么样本量很大时 p 值"容易显著"，此时应怎么下结论

## 2. AB 实验

> 📍 教学 → 01-AB实验设计与评估.ipynb

- [ ] 完整 AB 实验流程：假设 → 指标 → 样本量 → 分流 → 运行 → 分析 → 决策，各环节质量关卡
- [ ] 实验指标设计：主指标 / 护栏指标 / 反向指标；为什么不只看一个指标
- [ ] 样本量公式：两样本均值比较 n = 2σ²(z_{α/2}+z_β)² / δ²，各符号含义；比例指标版本
- [ ] 最小可检测效应（MDE）：定义、如何结合业务设定、与样本量的关系
- [ ] 随机化单位选择（用户/设备/行为），同用户多次曝光如何保证独立
- [ ] 分层随机（stratified）的作用与适用场景；层化与 CUPED 的联系
- [ ] 互斥实验与正交/重叠实验框架（Google 重叠实验平台思路），为什么实验组之间要互斥
- [ ] AA 检验：目的、做法与通过标准；失败的可能原因（分流不均/数据质量问题）
- [ ] SRM（样本比例不匹配）：检测方法（卡方）、常见诱因（埋点丢失/时间窗口截断/用户跃迁）、对结论的影响
- [ ] 显著性检验方法选型：z/t 检验、置换检验、非参（Mann-Whitney U）；ratio 指标（人均/ARPU）为什么不能直接 t 检验
- [ ] 连续监控（peeking）为什么导致假阳性膨胀（等价于多重比较）
- [ ] 修正方案：固定样本量 / alpha spending / 序贯检验（sequential testing）直觉
- [ ] p-hacking 与事后子群体分析（subgroup analysis）的风险
- [ ] 报告实验结果的正确姿势：点估计 + 置信区间，而非只报 p 值
- [ ] CUPED 原理：协变量校正估计量 Ŷ_adj = Ȳ − θ(X̄ − μ_X)，θ = Cov(X,Y)/Var(X)，为什么能降方差、适用条件
- [ ] 其他方差缩减手段：层化、CUPAC/带 ML 协变量、双重稳健（doubly robust）直觉
- [ ] GAUC：为什么全局 AUC 会被流量占比/头部用户带偏；按分组加权 AUC 的计算
- [ ] 辛普森悖论在 AB 实验中的表现（整体负、分组全是正）与处理（层内估计/加权）
- [ ] 实验未显著怎么办：功效不足 vs 真无效，如何用置信区间判断"不显著 ≠ 没效果"
- [ ] 多臂老虎机（MAB）vs AB 实验：什么时候适合用 MAB 做探索，与固定样本实验的取舍
