# 🔁 06-面试复盘

> 复盘是秋招提升最快的方式：**一场高质量的复盘 > 刷 10 道新题**。

## 复盘方法论

1. **24 小时内完成**：记忆最清晰时记录，越拖越失真
2. **只记事实，不贴标签**：记录"问了什么、我答了什么"，不写"我太菜了"
3. **三次追问**：
   - 答得好的：好在哪里？能否复现？
   - 答得不好的：卡在哪一步（没理解题/没准备到/表达混乱）？
   - 没被问的：哪些高频考点这场没考，下次可能考？
4. **反哺清单**：新考点 → 写进对应模块清单；薄弱点 → 排进下一周计划
5. **每周总结**：看趋势（哪些坑反复出现），不止看单场

## 使用流程

```
每场面试后 → 复制 复盘模板.md 为 模板-公司-岗位-日期.md
           → 当场记录（可以先记关键词）
           → 24h 内补全
           → 新考点回填对应模块清单
           → 下周计划加入薄弱点
```
