## 面试 30 秒速答（背诵骨架）

- **Momentum**：`v ← βv + g`，记忆历史方向 → 抑制震荡、加速穿越平坦区
- **Adam**：一阶矩（方向）+ 二阶矩（逐参数步长）+ 偏差校正 `1-β^t`；默认 `lr=1e-3, β₁=0.9, β₂=0.999`
- **AdamW**：权重衰减从 L2 正则中**解耦**，直接乘到参数上，避免与自适应步长耦合 → LLM 默认
- **warmup**：前期梯度方差大，直接大步长会破坏预训练分布 → 线性升到峰值再衰减
- **梯度裁剪**：`g ← g·clip_norm/max_norm`，防梯度爆炸（RNN/LLM 必用）
- **为什么不用二阶**：Hessian 是参数量平方级，7B 模型存不下 → K-FAC/Shampoo 近似或干脆不用
- **混合精度**：BF16 宽指数保范围（LLM 主流）、FP16 需 loss scaling、FP32 master copy 保累加精度
