## 面试 30 秒速答（背诵骨架）

**训练优化器**
- **Momentum**：`v ← βv + g`，记忆历史方向 → 抑制震荡、加速穿越平坦区
- **Adam**：一阶矩（方向）+ 二阶矩（逐参数步长）+ 偏差校正 `1-β^t`；默认 `lr=1e-3, β₁=0.9, β₂=0.999`
- **AdamW**：权重衰减从 L2 正则中**解耦**，直接乘到参数上，避免与自适应步长耦合 → LLM 默认
- **warmup**：前期梯度方差大，直接大步长会破坏预训练分布 → 线性升到峰值再衰减
- **梯度裁剪**：`g ← g·clip_norm/max_norm`，防梯度爆炸（RNN/LLM 必用）
- **为什么不用二阶**：Hessian 是参数量平方级，7B 模型存不下 → K-FAC/Shampoo 近似或干脆不用
- **混合精度**：BF16 宽指数保范围（LLM 主流）、FP16 需 loss scaling、FP32 master copy 保累加精度

**经典优化算法**
- **LP**：可行域是凸多面体，最优解在顶点；单纯形沿边移动、检验数判优；对偶给影子价格
- **IP**：LP 松弛解是上界、取整不可靠（可能不可行）；分支定界靠「上界 ≤ 下界」剪枝
- **GA**：选择（压力）+ 交叉（重组）+ 变异（多样性）+ 精英（不倒退）→ 黑箱问题的默认启发式
- **SA**：Metropolis `P=exp(-Δ/T)`，高温探索、低温收敛；不用梯度、只要目标值
- **TS**：禁忌表防回环，藐视准则破「更好但被禁忌」的移动
- **PSO**：`v ← w·v + c₁r₁(pbest−x) + c₂r₂(gbest−x)`，惯性 + 认知 + 社会
- **ACO**：转移概率 ∝ τ^α·η^β，信息素「蒸发防早熟 + 沉积正反馈」，天生适合路径类
- **KKT**：平稳性 + 原始可行 + 对偶可行（μ≥0）+ 互补松弛（μ·g=0）→ SVM 支持向量/正则化/Lasso 稀疏
