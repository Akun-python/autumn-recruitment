# 🤖 02-机器学习

> 目标：面经全覆盖 + 关键推导能手推。面试考察的不是"背过概念"，而是 **能推导、能对比、能讲场景**。

## 复习策略

1. **先搭框架**：监督 / 无监督 / 半监督、回归 / 分类 / 聚类 / 降维 / 生成
2. **每个模型三件套**：模型假设（公式）→ 学习算法（怎么优化）→ 适用场景与局限
3. **手推优先**：LR、SVM、PCA、LDA 是高频手推题，务必独立推导 3 遍以上
4. **会对比**：LR vs SVM、GBDT vs XGBoost vs LightGBM、L1 vs L2、PCA vs LDA 这类对比题必考
5. **结合场景**：每一个考点想一个真实业务例子（CTR、推荐、风控）
