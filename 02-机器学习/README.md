本模块是一本**可以按顺序读的书**，知识全部在 notebook 里：

**推荐阅读顺序**：`00-总览`（半小时搭框架）→ `01-线性回归` → `02-逻辑回归` → `03-朴素贝叶斯与K-Means` → `08-KNN` → `04-SVM` → `07-决策树与随机森林` → `09-AdaBoost` → `06-GBDT` → `10-神经网络与反向传播` → `05-PCA` → `11-HMM` → `12-CRF与最大熵` → `13-特征工程与模型评估`。面试前用 00-总览的**公式速查表**过公式、**对比总表**背对比题。

## 复习策略

1. **先搭框架**：监督 / 无监督 / 半监督、回归 / 分类 / 聚类 / 降维 / 生成
2. **每个模型三件套**：模型假设（公式）→ 学习算法（怎么优化）→ 适用场景与局限
3. **手推优先**：LR、SVM、PCA、LDA、BP、Viterbi、AUC 是高频手推题，务必独立推导 3 遍以上
4. **会对比**：LR vs SVM、GBDT vs XGBoost vs LightGBM、AdaBoost vs GBDT、HMM vs MEMM vs CRF、L1 vs L2、PCA vs LDA 这类对比题必考
5. **结合场景**：每一个考点想一个真实业务例子（CTR、推荐、风控、序列标注）
