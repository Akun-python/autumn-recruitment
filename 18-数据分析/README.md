## 学习路线（推荐顺序）

1. **打底（00）**：业务指标与描述性统计——均值/中位数/方差/IQR 手写 vs numpy、DAU/留存/转化/ARPU/GMV ✅
2. **数据基本功（01-02）**：数据清洗（缺失/重复/离群/类型）→ 分组聚合与透视表（手写 groupby vs pandas、复购率、top-N）✅
3. **分析方法（03-05）**：留存同期群矩阵与留存曲线 → 漏斗分析与转化率（定位最大流失环节）→ RFM 用户分层与运营动作 ✅
4. **SQL 与取数（07）**：窗口函数三排名 / 组内 top-N / 连续登录 / 留存 SQL / 行列转换 / 环比·同比 / 取数规范 ✅
5. **实验与建模（08-10）**：AB 实验业务落地（z/t 检验、样本量、AA/SRM、peeking）→ 数据可视化规范 → 相关与回归分析（OLS/R²/共线性）✅
6. **综合冲刺（06、11-12）**：时序指标监控（3σ 预警）→ 商业分析综合案例（口径→拆解→下钻→验证→建议）→ 数据分析面试八股 ✅

## 面试高频题型（详见 [高频面试题.md](高频面试题.md)）

- **指标口径类**：DAU/MAU、留存率（分母陷阱）、转化率、ARPU/ARPPU、GMV 拆解、北极星指标
- **数据处理类**：缺失值处理方式与取舍、离群值判据（z-score/IQR）、去重、透视表、top-N
- **分析方法类**：同期群怎么算、漏斗怎么定位流失、RFM 怎么打分分层、辛普森悖论
- **SQL 类**：三种排名区别、组内 top-N、连续登录、留存 SQL、行列转换、LAG 环比
- **实验类**：样本量、AA/SRM、peeking、护栏指标、显著性 vs 效应量
- **回归类**：皮尔逊 vs 斯皮尔曼、OLS 闭式解、R²、多重共线性、回归 ≠ 因果
- **案例类**：日活下降怎么排查、收入下滑怎么定位、活动效果怎么评估、新功能怎么验证
