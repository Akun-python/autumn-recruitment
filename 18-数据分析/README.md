## 面试高频题型（详见 [高频面试题.md](高频面试题.md)）

- **指标口径类**：DAU/MAU、留存率（分母陷阱）、转化率、ARPU/ARPPU、GMV 拆解、北极星指标
- **数据处理类**：缺失值处理方式与取舍、离群值判据（z-score/IQR）、去重、透视表、top-N
- **分析方法类**：同期群怎么算、漏斗怎么定位流失、RFM 怎么打分分层、辛普森悖论
- **案例类**：日活下降怎么排查、活动效果怎么评估、新功能怎么验证、指标体系怎么建
