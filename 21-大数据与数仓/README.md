# 🏗️ 21-大数据与数仓：Hadoop / Spark / Flink / Hive 数仓 / Kafka / 调度

> 大数据岗位（离线/实时/数仓）面试覆盖 **HDFS、MapReduce、Spark、Flink、Hive 分层建模、
> Kafka 管道、调度与治理**。本模块用 **Python 模拟实现**讲透每个核心机制：
> 分块副本、Map/Shuffle/Reduce、RDD 惰性求值与血缘、窗口与水位线、
> ODS→DWD→DWS→ADS 四层数仓（sqlite3 实战）、分区与偏移量、DAG 调度。
>
> 面向秋招画像：**大数据开发、数据仓库、实时计算、数据平台、数据工程** 岗位。
> 前置衔接：17-数据科学（SQL/数据分析）、18-数据分析（业务指标）、
> 02-机器学习（特征工程，算法特征产出依赖数仓）。

> 🖼️ 教学 notebook 全部基于 numpy/pandas/matplotlib/sqlite3，无需集群即可运行，
> 含断言与数值对照（含与 pandas/SQL 的交叉验证）；绘图统一中文字体并显式 `plt.show()`。

## 面试高频题型（详见 [高频面试题.md](高频面试题.md)）

- **存储类**：HDFS 分块与副本、NameNode 单点、小文件问题、存算分离
- **离线计算类**：MR 三阶段、Shuffle 为什么慢、Spark vs MR、RDD 血缘、宽窄依赖
- **实时计算类**：事件时间 vs 处理时间、Watermark、窗口类型、迟到数据处理、精确一次
- **数仓类**：四层职责、星型 vs 雪花、指标口径统一、数据倾斜、SCD 慢变维
- **管道类**：Kafka 分区与有序性、消费者组与重平衡、消息积压、ACK 三档
- **平台类**：DAG 调度与依赖、失败重试、血缘用途、数据质量四维度
